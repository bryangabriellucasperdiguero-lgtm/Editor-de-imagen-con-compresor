Proyecto CP

Aplicación gratuita desarrollada en Python que reúne un editor de imágenes, un compresor de archivos y un formato propio de imagen llamado CP.

Funciones

Editor de imágenes

- Edición con un máximo de dos capas.
- Lápiz y borrador.
- Dibujo de líneas, rectángulos y círculos.
- Selector de colores y cuentagotas.
- Zoom.
- Añadir texto.
- Recortar y redimensionar.
- Rotar y voltear imágenes.
- Ajustes de brillo y contraste.
- Filtros de blanco y negro, sepia y negativo.
- Deshacer y rehacer.

Compresor de archivos

- Comprimir archivos en formato ".cp".
- Recuperar archivos comprimidos.

Formato de imagen CP

- Conversión de imágenes al formato ".cp".
- Compresión sin pérdida.
- Compresión con pérdida.
- Conservación de transparencia.

Requisitos

- Python 3
- Pillow
- Tkinter

Instalación

Instala la dependencia:

pip install -r requirements.txt

Ejecuta el programa:

python proyecto_cp.py
